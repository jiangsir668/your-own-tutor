# 教程大师

> 教学之道，不在多言。在其所授，必验其所得。

扔材料进来 —— PDF、PPT、Word、视频都行。自动提取，萃脉络，按你的偏好织成课。逐章教，每教一个概念，追着你问。讲得出才算你的，讲不出回头再来。

## 六阶段

1. **摄材** —— PDF 用 `pdftotext`，PPT 用 LibreOffice 转，Word 用 python-docx，视频走 bilinote / yt-dlp。收完报告清单。
2. **萃髓** —— 八项提炼：核心洞见、问题诊断、解决框架、关键原则、证据偏好、实践应用、警示、愿景。
3. **画像** —— 两轮问卷采集认知偏好（大局 / 细节、节奏、反馈方式）。有旧档则跳过。
4. **架构** —— 画概念依赖树，每章填七字段：时长、前置、学习目标、锚点问题、视觉锚点、反例陷阱、自测题。附回旋追踪表 + 素材矩阵 + 缺口标注。
5. **筑课** —— 逐章写，禁令：不定义开场、不无图纯推导超3分钟、不超10分钟无停点、不跳过反例。每章含掌握清单、回旋追踪、习题映射、下章预告。
6. **授验** —— 每教一个概念，四步循环。

## 授验四步

**教** —— 锚点开场，讲案例，讲完不急于亮答案。先问：你用自己话说，怎么判断？

**问** —— 听你自陈。不打断。

**对** —— 亮讲义标准答案，和你的回答对照。指出抓住了什么、漏了什么。

**验** —— 费曼追问。以答案撞直觉。给新例、抛反例。每轮抓最含糊那句追问，挑最脆的论断挑战。不放过任何"本质上"、"核心就是"。换词不换义则指破。语气不客气——讲不清就是没懂。

**判** —— 出诊断。真懂与似懂分列。似懂非空，不准前进。回炉两次仍不过则暂挂，先走别章，最后补。

## 格式支持

| 格式 | 方法 |
|------|------|
| PDF | `pdfinfo` → `pdftotext -layout`，图页 `pdftoppm` 栅化 |
| PPT (旧版) | `libreoffice --headless --convert-to pdf` → 同 PDF |
| Word | `.docx` 用 python-docx，`.doc` 转 PDF 后提取 |
| 视频 | bilinote > bilibili/youtube-render-pdf > yt-dlp + watch 兜底 |

## 使用

将 `SKILL.md` 放在 `.claude/skills/jiaocheng/`。呼「备课 / 教我 / 课程架构 / 继续下一章」即启。

### 示例

```
用户：备课，这些是教材
      [上传 邏輯課程講義_傅皓政 文件夹，含12个PPT + 作业 + 参考档]
      [发送 B站链接 https://www.bilibili.com/video/BV1iCdoYKEgf]

jiaocheng：
  → 阶段1：提取12份PPT文本 + 获取视频100集目录
  → 阶段2：萃取傅皓政教学DNA（通识导向、形式与内容分离、反例驱动）
  → 阶段3：画像采集 → 两轮问卷（偏好：先大局、怕抽象、讲一段停一段）
  → 阶段4：画13章概念依赖树 + 锚点问题 + 回旋追踪表
  → 阶段5：构建第1章互动课程 → course-chapter-01.md
  → 待用户说「教我第1章」

用户：教我第1章

jiaocheng：
  教：A→ 所有人会死 + 苏格拉底是人 → 苏格拉底会死
      B→ 所有人会死 + 苏格拉底会死 → 苏格拉底是人
      直觉告诉你A对B错。用你自己的话说，差别在哪？
  问：用户答「A有效因为苏格拉底包含在人的范围里」
  对：亮标准答案——有效性 = 不可能前提全真而结论为假。
      你的回答抓住了包含关系，但没说为什么B不行。
  验：[费曼追问] 包含关系能解释「天下雨→地湿」这种论证吗？
      里面没有包含关系，但它仍然有效——你的模型不够。
  …
  判：真懂：有效与真假无关、包含关系是一种有效形式。
      似懂：说不出有效性的统一判准、追问中"结构关系"未落地。
      回炉，从标准答案重来。
```

## 戒律

1. 不跳过提取直接萃取
2. 不用定义开场
3. 不费曼追问不到位就诊断
4. 不放过含混回答
5. 不连续讲授超10分钟无停点
6. 不跳过反例上习题
7. 不用"大致""基本"带过错误
8. 不答非所问超两次不拉回
9. 不教完案例立刻亮答案 —— 先让学习者自陈
10. 不讲完整章再验 —— 每概念即教即验即判
