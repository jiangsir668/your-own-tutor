# 教程大师

> **教一个概念，验一个概念。讲得出来才是你的。**

扔材料进来——PDF、PPT、Word、视频都行。自动拆解，萃脉络，按你的脑回路织成课。逐章教。每教一个概念，费曼追身打：反问、拆词、抛反例、捅模糊句。过不了不准往下走。

## 怎么用

把 `SKILL.md` 丢进 `.claude/skills/jiaocheng/`。说「备课」「教我」就启动。

### 一镜到底

```
用户：备课 [上传逻辑学讲义12份PPT] [甩入B站视频链接]

jiaocheng：
  ▸ 提取12份PPT文本 + 视频100集目录
  ▸ 萃取傅皓政教学DNA
  ▸ 两轮问卷 → 画像（先全景、怕抽象、一段一消化）
  ▸ 画出13章概念依赖树 + 回旋表
  ▸ 构建第1章 → course-chapter-01.md

用户：教我第1章

jiaocheng：
  教  所有人会死。苏格拉底是人。所以苏格拉底会死。
      所有人会死。苏格拉底会死。所以苏格拉底是人。
      直觉告诉你A对B错——用你自己的话说，差在哪？

  问  用户："A有效因为苏格拉底包含在人里。"

  对  亮答案：有效性 = 不可能前提全真而结论为假。
      你抓住了包含关系。漏了——为什么B不行？因为存在一个世界：
      苏格拉底是狗、也会死、但不是人。找到了"前提真结论假"的可能。

  验  丢新例："如果天下雨，地就会湿。天下雨了。所以地湿了。"
      这里面有包含关系吗？没有。按你的模型它不该有效——但它有效。
      你的模型不够。重新说。

  判  ✅ 有效与真假无关、包含关系确是一种
      ❌ 说不出统一判准，"结构关系"四个字下是空的
      ↻ 回炉，从定义再来。
```

## 六步一条线

```
摄材 ──→ 萃髓 ──→ 画像 ──→ 架构 ──→ 筑课 ──→ 授验
 │          │        │        │        │        │
 PDF/PPT   八脉     两轮     依赖树   逐章写   ⚡ 教→问→对→验→判
 视频/Word 提炼     问卷     回旋表   戒律六条  逢概念必循环
```

## 十条铁律

① 不跳过提取直接萃取 ② 不用定义开场 ③ 费曼追问不到位不诊断 ④ 不含糊放过 ⑤ 不超10分钟无停点 ⑥ 不跳反例上习题 ⑦ 不用"大致""基本"带错误 ⑧ 不答非所问超两次不拉回 ⑨ **不教完案例立刻亮答案——先让你自陈** ⑩ **不讲完整章再验——每概念教→对→验→判**
