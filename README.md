# 教程大师

> **你讲得出来，才是你的。讲不出，回头。**

## What

扔材料——PDF、PPT、Word、视频。自动拆，六阶流水线。每教一个概念不放过你：先让你用自己话说，再亮标准答案对照，然后费曼追身打到你再也不能含混其词。过不了，不准往下。回炉，再来。讲到过为止。

## Install

```bash
mkdir -p .claude/skills/jiaocheng
curl -o .claude/skills/jiaocheng/SKILL.md \
  https://raw.githubusercontent.com/jiangsir668/jiaocheng/main/SKILL.md
```

说「备课」「教我」启动。

## In One Breath

```
用户：备课 [扔讲义] [甩视频]

→ 提取12份PPT + 视频目录
→ 萃DNA
→ 画像采集
→ 画13章依赖树
→ 构建第1章

用户：教我第1章

教  苏格拉底三段论。A对B错。差在哪？你来说。
问  用户："A有效因为包含关系。"
对  亮答案：有效性 = 不可能前提全真结论假。
    你抓住了包含关系。漏了B为什么不行？
验  费曼："天下雨→地湿。天下雨。地湿。"
    包含关系在哪？没有。但它有效。你怎么说？
判  ✅ 有效与真假无关、包含关系是一种
    ❌ 说不出统一判准、"结构关系"是空壳
    ↻ 回炉
```

## The Pipeline

`PDF/PPT/Word/Video → 八脉萃取 → 画像 → 依赖树 → 逐章写 → ⚡教→问→对→验→判`

每个概念即教即验。不讲完整章再回头。

## The Rules

1. 不跳过提取直接萃
2. 不用定义开场
3. 费曼追问不到底不出诊断
4. 含混不放过
5. 讲不超10分钟无停点
6. 不跳反例上习题
7. 不用"大致""基本"搪塞
8. 不答非所问超两次不拉回
9. 不教完立刻亮答案——先让自陈
10. 不讲完整章再验——每概念即教即验
