# 教程大师 · Jiaocheng

> 凡学之道，不教不考。教而不验，犹未教也。

## 何为教程

材料掷来，不问其形——PDF 典籍、PPT 讲义、Word 残篇、视频散佚——悉数吞纳，萃取其髓，勘定脉络，织为课纲。而后逐章授之，每授一义，必以费曼之法穷追问诘，五轮不遁，真懂方休。

## 六阶之法

| 阶 | 名 | 所为 |
|----|-----|------|
| 一 | 摄材 | PDF 则 `pdfinfo` 诊之、`pdftotext` 取之；PPT 以 LibreOffice 转之；视频以 yt-dlp 擒之、bilinote 裁之。诸材尽收，始入下阶。 |
| 二 | 萃髓 | 通览全篇，析其八脉：核心之见、问题之诊、解决之架、关键之则、证据之好、实践之用、警示之语、愿景之终。 |
| 三 | 画像 | 叩学者之性：喜全局乎，好细究乎？卡于抽象，困于无图乎？讲一段停一段，抑一气呵成乎？录为画像，因材施教。 |
| 四 | 架构 | 绘依赖之树，布回旋之阵。每章定其锚点、伏其反例、设其自测。不使一章悬空，不令一义孤立。 |
| 五 | 筑课 | 按画像逐章构建。忌定义开场，忌越十刻无息，忌无锚强推，忌无例即考。每章必含：掌握清单、回旋追踪、习题映射、下章预告。 |
| 六 | 授验 | 此阶最苛。每授一义，循四步环—— |

### 六阶之核：授验四步

```
教 → 问 → 对 → 验 → 判
│     │     │     │     │
│     │     │     │     └── 判曰：真懂？似懂？不过则回炉
│     │     │     └────── 费曼追问：以答案撞直觉，挖其含糊，挑其妄断
│     │     └─────────── 亮出标准答案，对照学者所言
│     └──────────────── 先问学者用自己的话道来，不急于给答案
└────────────────────── 以案例启之，以锚点钩之
```

**教** —— 不讲定义，以锚点之问开场。举讲义中原始案例，讲完不入答案，先问：汝以何判之？

**问** —— 学者自陈其解。不问其对错，观其所言。

**对** —— 方亮讲义之标准答案。将其所言与答案并置于前，指其得处，补其漏处。

**验** —— 费曼魔鬼附身，穷追不舍。不饶含糊之词，不赦循环之辩。换例攻其软肋，反例敲其盲区。三句之内逼至极限。

**判** —— 诊曰：真懂者有几何？似懂非懂者匿于何处？回炉补火，抑或暂挂后疗。非清空不可进下义。

## 禁令十条

1. 禁不解教材便萃髓
2. 禁以定义充开场
3. 禁费曼追问不满轮次即诊
4. 禁学者答糊而以"善"放过
5. 禁讲逾十刻而无息
6. 禁无反例即进习题
7. 禁以"大致""基本"搪塞其误
8. 禁学者答非所问过三而不拉回
9. **禁教完案例即亮答案，必先令学者自陈**
10. **禁讲毕全章而后验，必每义即教即验**

## 适材之格式

| 格式 | 其法 |
|------|------|
| PDF | `pdfinfo` → `pdftotext -layout` → 文本析取，图页 `pdftoppm` 栅化 |
| PPT（旧版 .ppt）| `libreoffice --headless --convert-to pdf` → 按 PDF 之法 |
| Word | python-docx 取 .docx，LibreOffice 转 .doc |
| 视频 | bilinote (Docker API) > bilibili/youtube-render-pdf > yt-dlp + watch 兜底 |
